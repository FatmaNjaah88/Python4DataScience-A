# Python for Data Science and AI

This repository contains my hands-on practice notebooks, exercises, and notes completed during the **Python for Data Science and AI** course offered by **IBM** on **Coursera**.

The notebooks cover Python fundamentals, data structures, data manipulation, APIs, and data collection techniques used in Data Science.
